# Ludoteca

A cross-platform desktop app that pulls your owned games from Steam, GOG and Epic
into one local library you can sort and filter. Romanian *ludotecă*: a game library.

Electron + Vue 3 + SQLite. Design notes, backlog and plans live in `.claude/`
(symlinked into `llm-rulebase`).

## Status

Nothing is built yet. `spikes/` holds throwaway scripts that validate the risky
assumptions before the app is scaffolded around them — see the P0 items in the backlog.
